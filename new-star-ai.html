How to call the New Star API

Call this endpoint from your own server. Keep the New Star key out of browser JavaScript, mobile app bundles, public repositories, and screenshots.

Authorization: Bearer ns_live_YOUR_KEY

Use only the permissions granted to that key. Chat uses the messages field; image generation uses action: "image"; live search uses action: "search"; image understanding uses action: "vision".
