New Star Android

Download the Android installer from the official New Star GitHub release.

Download latest APK Open Android test builds
  1. Download the APK file to your Android phone.
  2. Open it from your Downloads folder.
  3. Review Android's installer and permission prompts, then choose Install if you trust this build.
  4. Open New Star and grant camera or microphone permissions only when you use those features.

Android always controls installation. It may ask you to confirm installing an app from the browser or file manager. Do not turn off Play Protect or bypass security warnings. A successful build is not a guarantee that every device or streaming feature has been tested.

For a stable public release, the repository maintainer must configure the private Android signing-key secrets before publishing a signed release.
